# UI Redesign Phase 2 — Public Landing 1c Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the public landing page as the "น้ำแพร่ Bold" (1c) design — topbar, LIVE SENSORS ticker, animated hero with air card + count-up stats, category-filtered hairline service grid, green footer — driven by the same `PublicConfig` SSG data as today.

**Architecture:** `index.tsx` stays SSG (`getStaticProps` + `revalidate: 60`) and passes config into new/rewritten components. Category filtering is client state (`cat`) layered over the static list. Live-looking numbers (PM2.5, ticker) come from a single mock module `src/lib/live-sample.ts` (pointer to future `/api/air`). Foundation pieces from Phase 1 are consumed here: `Icon`, `iconForService`, green tokens, `np-*` animation utilities.

**Tech Stack:** Next.js 16 pages router, Tailwind v4 tokens from Phase 1, Material Symbols subset font.

**Spec:** `docs/superpowers/specs/2026-07-29-ui-redesign-1c-design.md` · **Pixel reference:** `public/design_handoff_namphrae_ui/Namphrae UI ใหม่.dc.html` screens `1c Desktop` + `1c Mobile` (values below were extracted from that file — where the README's older 1c section disagrees, the file + update note win)

**Decisions baked into this plan (surface these in the final report):**
- **No search box.** The chosen 1c screens have category pills only (the search bar exists only in the unchosen 1a). The spec's mention of search is dropped to follow the prototype; can be added later.
- **H1 = "น้ำแพร่ / ทั้งตำบล" (2 lines).** The README update note says the user removed the "อยู่ในมือคุณ" line; the prototype file still shows it (not re-exported). The note is the documented decision — follow it. Emphasis word uses green-forest `#32523D`.
- **Sparkline colors from the file** (`<26 → #34B863`, `<38 → #8C8A2F`, `≥38 → #8A4A2A`), not the README's old AQI hexes.
- **Login button stays** in the topbar (user-requested feature from before the redesign), restyled to match 1c.
- **Hero media (site.hero video/image) is dormant** in 1c — the design uses the contour layer instead. `HeroMedia.tsx` stays in the repo unused; the admin setting keeps saving harmlessly. Flag to user.
- **Ticker hidden on mobile** (1c Mobile has none) and **PM2.5 drift is mock** (32 + rand 0..4 every 3.4s) per the approved show-sample-numbers decision.
- Old components `CategorySection.tsx`, `ServiceCard.tsx`, `ServiceThumb.tsx`, `ManualsSection.tsx`, `VisitorCounter.tsx` are deleted once unused (Task 7).

**Testing note:** No test runner. Gates: `npx tsc --noEmit`, `npm run lint`, `npm run build`, rendered smoke checks (Task 8). Click-tracking behavior (sendBeacon on click+auxclick, `_blank` per `openInNewTab`, `aria-disabled` when URL empty) must survive — it is asserted by grep in Task 5.

// 0→1 progress over `ms` with cubic ease-out; jumps to 1 for reduced motion.
function useCountUp(ms = 1600): number {
  const [p, setP] = useState(0);
  useEffect(() => {
    if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
      setP(1);
      return;
    }
    const t0 = performance.now();
    let raf = 0;
    const tick = (now: number) => {
      const t = Math.min(1, (now - t0) / ms);
      setP(1 - Math.pow(1 - t, 3));
      if (t < 1) raf = requestAnimationFrame(tick);
    };
    raf = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(raf);
  }, [ms]);
  return p;
}

function track(id: string) {
  if (typeof navigator !== 'undefined' && 'sendBeacon' in navigator) {
    navigator.sendBeacon(`/api/track/${encodeURIComponent(id)}`);
  }
}

function Cell({ link, index }: { link: PublicLink; index: number }) {
  const hasUrl = Boolean(link.url);
  const inner = (
    <>
      <span className="flex items-center justify-between">
        <Icon name={iconForService(link.id, link.icon)} size={34} className="text-green-deep" />
        <span className="font-display text-[11px] font-semibold tracking-[.14em] text-ink-mute">
          {String(index + 1).padStart(2, '0')}
        </span>
      </span>
      <span className="mt-auto">
        <span className="block font-display text-xl font-bold leading-[1.25] tracking-[-.01em] text-ink">
          {link.title}
        </span>
        {link.subtitle ? (
          <span className="mt-1.5 block text-[12.5px] leading-[1.55] text-ink-faint">
            {link.subtitle}
          </span>
        ) : null}
      </span>
    </>
  );

  const base =
    'flex min-h-[150px] flex-col gap-4 border-b border-r border-line bg-white p-6 transition-colors duration-[.18s] animate-np-rise';
  const style = { animationDelay: `${index * 55}ms` };

  if (!hasUrl) {
    return (
      <div aria-disabled="true" className={`${base} cursor-default opacity-70`} style={style}>

      href={link.url}

      style={{ ...style, outlineColor: accentFor(link.categoryId) }}
