# Handoff: ระบบสารบรรณอิเล็กทรอนิกส์ — เทศบาลตำบลน้ำแพร่พัฒนา

## Overview
ระบบสารบรรณสำหรับงานราชการ: ลงรับ/ส่งหนังสือ, เกษียนหนังสือออนไลน์ (พิมพ์สั่งการ, ลายมือ, ตราประทับ, ลงนามดิจิทัล), ติดตามเส้นทางหนังสือ, ค้นหา/แฟ้ม, พิมพ์ทะเบียน และแดชบอร์ดสถิติลดกระดาษ (แผ่น, บาท, CO₂)

มี **2 โหมด** ในระบบเดียว
- **โหมดกองฝ่าย / เต็ม** — สำหรับธุรการ/สารบรรณ หัวหน้ากอง: 8 หน้าจอ desktop/tablet
- **โหมดเจ้าหน้าที่** — รายบุคคล 3 หน้าจอ ทำงานได้ในไม่กี่แตะ (มือถือ/แท็บเล็ต)

## About the Design Files
ไฟล์ `.dc.html` ในชุดนี้เป็น **design reference ที่สร้างด้วย HTML** (prototype แสดงหน้าตาและพฤติกรรม) ไม่ใช่โค้ด production ให้คัดลอกไปใช้ตรงๆ งานของผู้พัฒนาคือ **สร้างใหม่ตามแบบนี้ในสภาพแวดล้อมของโครงการ** (React/Vue/Next/Laravel Blade ฯลฯ) ด้วย pattern และ library ที่มีอยู่ หากยังไม่มี ให้เลือก framework ที่เหมาะสมแล้วทำตามแบบ

เปิดดูได้โดยเปิด `ระบบสารบรรณ.dc.html` ในเบราว์เซอร์ (ต้องมี `support.js` และ `assets/` อยู่โฟลเดอร์เดียวกัน; ใช้ Google Fonts ต้องต่ออินเทอร์เน็ต)

## Fidelity
**High-fidelity** — สี ตัวอักษร ระยะ และ interaction เป็นค่าสุดท้าย ให้ทำตามให้ตรง แต่ใช้ component library ของโครงการได้ ข้อมูลทั้งหมดในต้นแบบเป็นข้อมูลจำลอง

## State (โหมดเจ้าหน้าที่)
`screen` (inbox/doc/receive) · `tab` · `docId` · `action` (ack/forward/circulate) · `draft` · `showPreview` · `recipients[] {id,name,on}` · `addingRecip/newName/newId` · `form` · `scanned` · `formError` · `docs[] {…, history[]}` · `toast`

## Interactions สรุป
- ทุก transition เป็น state switch ทันที ไม่มี route (แนะนำทำเป็น route จริง: `/dashboard /inbox /outbox /receive /annotate/:id /track/:id /search /report`, โหมดเจ้าหน้าที่ `/me /me/doc/:id /me/receive`)
- Hover: ปุ่ม accent → `#173d70`; ปุ่ม outline → bg `#F5F7FA`/`#F1F5FA`; แถวตาราง → `#F8FAFC`
- Focus: outline 2px accent offset -1
- วาดปากกา: canvas ขนาดเท่ากระดาษ, mouse + touch (touch-action none), เส้น 2px round cap
- ลงนามดิจิทัล: จำลอง — ของจริงควรผูกใบรับรอง (e.g. Thai Digital ID / CA) และ hash เอกสาร

## Backend/ข้อเสนอสำหรับทำต่อ
- สิทธิ์: ธุรการ/หัวหน้ากอง → โหมดเต็ม; เจ้าหน้าที่ทั่วไป/ผู้บริหาร → โหมดเจ้าหน้าที่ (มีสวิตช์ทั้งสองทาง)
- Audit trail ทุกการเกษียน/ลงนาม (ผู้ทำ, เวลา, IP, hash ไฟล์)
- สถิติกระดาษคำนวณจากจำนวนหน้าจริงของไฟล์แนบ × จำนวนผู้รับที่ไม่พิมพ์ ; ราคากระดาษและค่า CO₂/แผ่นเป็น config
- แจ้งเตือนผู้รับ (LINE/e-mail) เมื่อถูกส่งต่อ/แจ้งเวียน; แจ้งเตือนเกินกำหนด
- เลขทะเบียนรีเซ็ตตามปีงบประมาณ (1 ต.ค.)
